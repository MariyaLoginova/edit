# Эталон 40с · карточка «счётность» (FIX-3 приёмка)

Не для публикации — образец, к которому должен приближаться D2.
Объект: коты на улице. A/B: один → пятьдесят. Механизм: счётность.

| сек | бит | текст |
|---|---|---|
| 0–3 | хук | Один кот остановился перед тобой на улице. Смотрит. Уже хочется сказать «ми». |
| 3–10 | ложное | Кажется, чем больше таких мордочек — тем теплее станет кадр. |
| 10–26 | A/B | Добавь ещё двух — всё ещё мимими. Пять — уже «занятно». Десять — вопрос «чего это они?». А на пятидесяти ты замираешь: перед тобой не детёныши, а плотная масса хищников. Стоят. Смотрят. |
| 26–36 | механизм | Сработала **счётность**: тот же силуэт с большой головой на масштабе перестаёт читаться как «детёныш под опеку» и начинает читаться как стая. |
| 36–42 | формула | Один кот — умиление. Пятьдесят тех же котов — тревога. Милота ломается о количество. |

Проверки эталона:
- есть явный A/B одного объекта;
- механизм назван одним термином и через признаки;
- формула только в конце;
- нет «странно, но» / «формула простая» / «заметь».
