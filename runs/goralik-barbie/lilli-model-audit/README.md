# Аудит моделей · Барби ← Лилли

## Главный файл

[`audit.csv`](audit.csv) — полный CSV-аудит. Каждая строка содержит:

```text
model, stage, sent_system, sent_user, received, next_stage, status
```

Полный первичный блок книги сохранён отдельно в
[`00_source_block.txt`](00_source_block.txt), а также дословно находится в
строках C1 и в отправленных материалах D2/E-проверки.

## Вывод

- GPT-5.2 — рабочая основная модель личного D2-контура.
- Gemini 3.6 — отвечает содержательно, но для этого формата слишком агрессивно
  сокращает монолог; не ослабляем словный гейт ради модели.
- Grok 4.5 не подменяется другой моделью: ошибка записана как результат
  сравнения.
