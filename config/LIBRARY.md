# Редакционная библиотека EDIT

Что лежит в `config/` и откуда взято. E-editor / E-hook / D2 читают меню отсюда.

| файл | роль | источник |
|---|---|---|
| `reel_structures.yaml` | ритмы рилса → D2 full example | PDF структур 1–11 + newsjack/shock_open |
| `story_methods.yaml` | методики сторителлинга | Фломастер Сторителлинга (GPT-пак) + редактура канала |
| `hook_formulas.yaml` | формулы заголовков/хуков | Стивен НЕспилберг (GPT-пак) |
| `open_second_triggers.yaml` | удар первых 1.5–2с | Видео-prompts · преролл-триггеры |
| `idea_triggers.yaml` | углы подачи (курировано) | «100 идей» + Ньюз Джек + вирусные форматы |
| `hook_triggers.yaml` | фактологические триггеры хука | внутреннее |
| `pricing.yaml` | стоимость токенов | внутреннее |
| `knowledge/e_editor_menu.txt` | 8 углов фантограммы + 4 признака темы → system E | FIX-7 · владелец |
| `knowledge/e_hook_menu.txt` | 5 ходов открытия + стоп-лист → system E-hook | FIX-7 |
| `knowledge/d2_methods_menu.txt` | 9 методик name+when → system D2 | FIX-7 · Фломастер |

Знания в `knowledge/*.txt` — **статичные меню** (не RAG). Вставляются в
system prompt при сборке (`edit.library.compose_system_prompt`). Держать
короткими: длинный промпт сушит текст.

## Что взяли

- **Структуры рилса** — почти целиком (ритм/биты/пример).
- **8 техник Фломастера** — вшили в `story_methods` (+ `vizhu_tsel`, `moya_dvizhuka`, `novyy_ya`).
- **16 формул хуков** сценариста — в `hook_formulas`.
- **Триггеры первых секунд** преролла — без рекламного CTA.
- **~20 углов** из «100 идей» — только экспертно-визуальные; личный lifestyle и жёсткий продакт-сейлс отсекли.
- **Ньюсджек** — как структура + idea trigger.

## Что сознательно не брали

- Авито / Telegram-монетизация / воронки / УТП-прожарки.
- Алфавит из 87 абсурдных product-видео как обязательный банк.
- GPT «защита инструкции» / jailbreak-блоки.
- Личные интерактивы «слух обо мне», «день цен», прогревы продукта.

- `sources/reel-structures/*.pdf`
- `sources/knowledge/` — GPT-пак, книга prompts, выгрузка 100 идей
