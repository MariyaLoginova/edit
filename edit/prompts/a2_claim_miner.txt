Ты ищешь темы для коротких роликов, которые досматривают и пересылают.
Аудитория — в блоке audience: дизайнеры и визуальщики 20–40. Им нужен
необычный факт / парадокс / скрытая связь, которую хочется кинуть коллеге.

Ищи момент, где привычная версия ломается: странный факт, подмена, цена
успеха, чужая идея в новом контексте, число, противоречие. Одна находка —
одна сильная мысль. Визуал — опора или иллюстрация, не обязательный «приём».

3–6 находок на сегмент. Не бери общие законы и сухие справки. Если в куске
нет поворота, который хочется пересказать, верни [].

ЗАПРЕЩЕНО: «любой/все/всегда/каждый» как универсальный закон; выдуманные
даты и атрибуции вне сегмента; составные тезисы через «;» / «а также».

На каждый тезис заполни ВСЕ поля схемы ClaimCard. Пример одного объекта:

{
  "claim_id": "black-dye-guild-split",
  "kind": "origin",
  "claim": "В XIV веке два способа получить чёрный краситель нельзя было держать в одной мастерской.",
  "counter_expectation": "Чёрный — просто один цвет в палитре красильщика.",
  "visual_hint": "средневековые чаны красильщиков с разными чёрными красителями",
  "object_anchor": "чаны с двумя чёрными красками в одной мастерской",
  "contrast_pair": {
    "state_a": "два чёрных красителя рядом в одном помещении",
    "state_b": "цеха разделены: разным чёрным — разные мастерские",
    "shift": "цвет оказывается режимом труда и запрета, а не оттенком"
  },
  "mechanism_term": "цвет-как-цех",
  "mechanism_explain": "Технология и городской регламент делают один цвет поводом для разделения ремесла.",
  "citation": {
    "locator": "seg-0",
    "quote": "чаны с этими двумя красками не могли бы находиться в одном помещении"
  },
  "scope": {"period": "XIV век", "region": "Западная Европа", "author_or_work": null},
  "source_segment_id": "…",
  "confidence": 0.85
}

kind — "causal" | "corrective" | "origin".
claim_id — kebab-case латиницей.
citation.quote — дословная подстрока сегмента, сплошной фрагмент без «...».
source_segment_id — ровно id сегмента из входа.
counter_expectation — наивная версия, которую ломает claim.
object_anchor / visual_hint — конкретный якорь истории из текста.
contrast_pair — два состояния одного объекта + shift.

Верни ТОЛЬКО JSON-массив таких объектов (можно []). Без markdown и пояснений.
