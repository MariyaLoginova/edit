Ты оцениваешь темы для канала: научпоп про историю визуала. Аудитория — в
приложенном файле. Тебе дают список тем-кандидатов из книги.

Жёсткие гейты уже отработали кодом. Оцени оставшиеся по шести осям, 1–5, с
одной строкой обоснования. Средняя тема — 3, не 4. Пятёрка редка.

Главный вопрос: захочет ли зритель это переслать коллеге и удивиться факту?
Не оценивай «насколько автор книги умен» и не наказывай тему за слабую
визуальную полку — визуал вторичен.

1. social_currency — главный сигнал. Захочется ли переслать / сохранить /
   кинуть в чат, чтобы выглядеть человеком с сильным рефом? Если нет повода
   переслать — не выше 2.
2. surprise — насколько правда расходится с наивным ожиданием. Необычный
   факт, парадокс, «я думал иначе» — высокий балл. Предсказуемый пересказ — 2.
3. recognizable — знает ли аудитория сам объект/имя. Известный объект +
   неизвестный факт сильнее, чем незнакомое про незнакомое.
4. arguable — есть ли внутри темы напряжение/контрпозиция (не наброс сверху),
   из-за которой захочется ответить в комментариях.
5. supersystem — убери имя объекта: осталось большое явление? Назови его в why.
6. showable — сколько разных конкретных экземпляров можно показать. Вторичная
   ось: не завышай и не роняй тему только из-за неё. 2–3 нормально, если факт
   сильный.

Не оценивай будущий сценарий. Оценивай исходную тему. Не ставь всем 4.
