# EDIT-E3…E6 · Полная редактура (веха 4)

**Слой:** E3 красный критик, E4 перебор открытий, E5 тест пересказа, E6 сжатие  
**Вход:** `ScriptDraft` (+ frozen `Dossier`, `RetentionReport` из E2)  
**Выход:** обновлённый `ScriptDraft` + отчёты; финальный `blocked_for_production`

---

## Разделение ролей

| Узел | Бьёт по | Пишет текст? |
|---|---|---|
| E2 | динамика / отвал | нет (диагностика) |
| E3 | содержание («банально, не следует») | нет (разнос) |
| E4 | первые 3 сек | да — только opening |
| E5 | пересказ ↔ кода | нет |
| E6 | длина / filler | да — сжатие всего текста |

Инвариант 2: разные вызовы, разные промпты. E3 не чинит — только атакует.
Правки openings/длины — на E4/E6 по отчёту E2.

---

## Контракты

См. `models/editorial.py`.

- `RedCritique` — `passes=false` при любом attack `severity>=4`
- `OpeningPick` — 5–8 вариантов, `chosen_index`, обновлённый `script`
- `RetellReport` — одно предложение + сверка с кодой
- `CompressionReport` — `reduction_ratio` в окне из `config/thresholds.yaml` (editorial)

---

## Граф (веха 4)

```
… → E1 → E2 → E3 → E4 → E5 → E6 → editorial_gate
```

`editorial_gate` блокирует прод, если падает E1, E2, E3 или E5.
E6 `passes` — качество сжатия; не единственный стоп-кран.

---

## Критерии приёмки

- [x] E3 не возвращает переписанный сценарий — только атаки.
- [x] E4 даёт ≥5 вариантов и подменяет первые ~3 сек.
- [x] E5 `passes` требует цитируемую коду и совпадение пересказа.
- [x] E6 пересчитывает `reduction_ratio` детерминированно; чужой claim_id → fail.
- [x] Юнит-тесты на FakeLLM без сети.
