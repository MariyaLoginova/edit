# Политика ошибок и экономии LLM-вызовов

## Штатный личный контур

Ровно три LLM-вызова:

```text
E-редактор → D2 → E-проверка
```

`C1`, freeze и E1 — кодовые операции.

## Ошибки

| случай | действие | повтор |
|---|---|---|
| D2 дал 32 слова вместо целевого диапазона | передать в quality-gate; если <70 слов — кодовый блок | нет |
| D2 дал служебную оболочку / «Формула простая» | удалить только служебный префикс | нет |
| E-проверка дала битый JSON | вернуть технический блок с причиной | нет |
| Gemini policy block («sensitive words», prohibited use) | пометить модель disabled для run и перейти к следующей fallback-модели | один переход |
| transient/provider error (`NoneType`, timeout, quota) | записать ошибку и остановить конкретный прогон | нет |
| содержательный E-block | человек выбирает новую методику/тему/правку | не автоматический |

## Что не делаем

- Не повторяем один и тот же prompt до тех пор, пока модель случайно не угадала
  длину или JSON.
- Не ослабляем фактчек, чтобы модель прошла.
- Не подменяем недоступную модель другой без записи в аудит.
