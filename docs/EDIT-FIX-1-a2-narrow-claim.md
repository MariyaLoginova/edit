# EDIT-FIX-1 · A2: узкий тезис вместо универсального закона

**Приоритет:** 1 из 3 (корневая причина — делать первым)
**Меняет:** контракт `ClaimCard`, промпт A2
**Тестовый источник:** эссе Линор Горалик об умилении (linorgoralik.com/mimi.html)

---

## Диагноз

На богатом источнике A2 выдал ОДИН универсальный закон («любой милый объект
хрупок») вместо нескольких узких тезисов. Дальше всё посыпалось по цепочке:

- E3 справедливо: overclaim, severity 5.
- Из универсального закона D физически не может собрать разбор A→B→C — только
  мораль. Отсюда «мило → странно → формула».
- Аудит верно отметил потерю сток-щенка с поводком. Но потерян он не в D — A2
  вообще не выделил его в отдельную карточку.

**Корневая причина шире:** норма канала (хук-кадр → ложное объяснение → A/B →
механизм → формула) нигде не выражена как КОНТРАКТ. Она живёт в бит-шаблоне D1
как намерение, а не как обязательные поля. Поэтому D вынужден изобретать A/B и
механизм на ходу — из замороженного досье, где их нет.

**Решение: зашить норму канала в контракт добычи.** Если A/B и механизм —
обязательные поля `ClaimCard`, то тезис без них не проходит, а D получает
готовый каркас середины, а не выдумывает его.

---

## Что источник обязан был дать

Проверка на реальном тексте: эссе содержит минимум четыре тезиса каналового
уровня, каждый с объектом и встроенным A/B.

| Объект | A/B | Механизм |
|---|---|---|
| Сток-щенок с поводком и подписью «Гулять пойдём?» | ваш питомец ↔ безличный сток, просящий того же | коммуникация без вовлечённости, «забери домой» |
| Каваий-персонаж | «мило, потому что красиво» ↔ «мило, потому что пропорции детёныша» | педоморфизм |
| Кот на улице | один кот ↔ пятьдесят котов | счётность: та же милота на масштабе переворачивается в тревогу |
| Мордочка из конфет на пирожном | целое ↔ надкушенное | хрупкость-как-таймер: умиление живёт только в застывшем миге |

Ни один из них не «любой милый объект». Все четыре — визуализируемы и содержат
два состояния одного объекта.

## Изменения контракта (Pydantic v2)

```python
class ContrastPair(BaseModel):
    """A/B — два состояния ОДНОГО объекта. Это каркас средней части ролика."""
    state_a: str = Field(..., max_length=200, description="Первое состояние/ракурс (напр. 'один кот на улице')")
    state_b: str = Field(..., max_length=200, description="Второе состояние того же объекта (напр. 'пятьдесят котов')")
    shift: str = Field(..., max_length=200, description="Что меняется в восприятии между A и B")


class ClaimCard(BaseModel):
    # ... существующие поля ...

    object_anchor: str = Field(
        ..., min_length=1, max_length=200,
        description="КОНКРЕТНЫЙ объект/кадр из источника, вокруг которого строится ролик. "
                    "Не категория ('милые вещи'), а вещь ('мордочка из конфет на пирожном')."
    )
    contrast_pair: ContrastPair = Field(
        ..., description="ОБЯЗАТЕЛЬНО. Без A/B средняя часть ролика превращается в пересказ тезиса."
    )
    mechanism_term: str = Field(
        ..., min_length=1, max_length=80,
        description="ОДИН называемый термин-механизм: 'педоморфизм', 'хрупкость-как-таймер', 'счётность'. "
                    "То, что зритель унесёт как знание."
    )
    mechanism_explain: str = Field(
        ..., max_length=300,
        description="Как механизм работает — через признаки, а не через имена авторов."
    )
```

### Валидаторы (hard fail)

```python
UNIVERSAL_MARKERS = ["любой", "любая", "любое", "все ", "всякий", "всякая",
                     "каждый", "каждая", "вся ", "всё ", "всегда"]

@field_validator("claim")
@classmethod
def _no_universal_law(cls, v: str) -> str:
    low = v.lower()
    for m in UNIVERSAL_MARKERS:
        if m in low:
            raise ValueError(
                f"claim сформулирован как универсальный закон ('{m.strip()}'). "
                "Нужен тезис про конкретный объект, а не про класс вещей."
            )
    return v
```

Плюс проверка: `object_anchor` должен упоминаться (лексически или по смыслу) в
`claim` — тезис привязан к вещи, а не парит над ней.

## Изменения промпта A2

Добавить к существующим правилам:

```
Извлекай 3-6 УЗКИХ тезисов на сегмент, а не один общий закон.

ЗАПРЕЩЕНО: формулировки вида «любой X…», «все X…», «всякое X…». Универсальный
закон нельзя показать одним кадром — значит это не тезис для ролика.

На каждый тезис ОБЯЗАТЕЛЬНО:
— object_anchor: конкретная вещь из текста, которую можно снять/показать;
— contrast_pair: ДВА состояния ОДНОГО объекта и что меняется в восприятии
  между ними. Если A/B не придумывается — тезис не годится, пропусти;
— mechanism_term: один называемый термин-механизм + объяснение через признаки
  (какие пропорции, какие черты, что именно на экране), НЕ через имена авторов.

УКЛОН КАНАЛА: мы про ВИЗУАЛЬНЫЙ ПРИЁМ, а не про культурологию чувства.
Если источник рассуждает об эмоции — тяни карточку в сторону «как устроен образ,
который эту эмоцию вызывает»: пропорции, фактура, композиция, количество,
момент во времени. Иначе получится пересказ автора, а не разбор кадра.
```

---

## Критерии приёмки

- [ ] Прогон на эссе Горалик даёт **≥3 карточки**, каждая с уникальным
      `object_anchor`.
- [ ] **Ни одной** карточки с универсальной формулировкой (валидатор режет).
- [ ] Среди карточек находятся минимум два из четырёх ожидаемых тезисов таблицы
      выше (сток-щенок / педоморфизм / счётность / таймер).
- [ ] У каждой карточки `contrast_pair` содержит два РАЗНЫХ состояния одного
      объекта, а не тезис и его отрицание.
- [ ] `mechanism_explain` описывает признаки, а не перечисляет фамилии.
- [ ] Регресс: на биографическом/проходном абзаце A2 по-прежнему молчит.

## Замечания

- Ожидаемо, что число карточек с сегмента вырастет, а «проходимость» упадёт:
  многие прежние карточки не соберут `contrast_pair` и отвалятся. Это цель, не
  побочный эффект.
- `contrast_pair` — самое ценное здесь. Он превращает «норму канала» из пожелания
  в структуру данных: если A/B есть в карточке, D не может его не показать.
- Не гнать эталонный сценарий и не чинить D, пока этот тикет не закрыт: на
  универсальном тезисе оба бессмысленны.
