# EDIT-FIX-5 · Пивот: не визуальная культура, а вирусные факты и мысли

## Решение

Канал больше не строится вокруг разбора визуального приёма. Его единица —
короткая история, в которой есть:

1. факт или парадокс, ломающий привычную версию;
2. нарастающая ставка, дающая причину досмотреть;
3. мысль, которую хочется переслать или применить к другой истории.

Финальная мысль может быть провокационной гипотезой, но обязана начинаться с
маркера мнения, например «А если…?». Тогда E1 не выдаёт её за подтверждённый
факт; фактическая часть до неё по-прежнему должна иметь `claim_id`.

Визуал — возможная иллюстрация на монтаже, не причина выбора темы и не гейт
сценария.

## Новый основной граф

```text
A2 (разведчик вирусных тем)
  → B2 (выбор человеком)
  → C1 (поиск фактов)
  → C3 (проверка источник + поиск, freeze)
  → D2 (история + голос + тайминг)
  → E1 (трассируемость)
  → E-критик (досмотр, факты, пересказ)
  → E4 (перебор хуков)
  → E7 (опциональная мысль)
```

`C2` и `F1` остаются отдельными утилитами для монтажа, но не входят в основной
редакционный контур и не блокируют публикацию.

## Контракты

- `ClaimCard` сохранён для обратной совместимости. Поля `object_anchor`,
  `visual_hint`, `contrast_pair` теперь означают конкретный якорь истории и
  её поворот, а не обязательный кадр.
- C3 и D2 freeze только по фактическому материалу: `material_notes` +
  `web_confirmations`. Картинки не обязательны.
- D2 больше не валидирует каждую реплику по токенам объекта. Валидирует
  фактический `claim_id`, таймкоды, длительность и стоп-фразы.

## Критерий качества

Не «можно ли это показать», а:

- ломает ли первая фраза привычную версию;
- есть ли новый факт / ставка по пути;
- следует ли мысль из источника;
- можно ли пересказать финал одним предложением.
- есть ли в финале гипотеза, которую хочется оспорить, а не мораль.
