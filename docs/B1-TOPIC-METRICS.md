# EDIT-B1 · Метрики виральности тем

B1 ранжирует темы, но не выбирает их вместо человека. Контракт:
`TopicCandidate → list[ScoredTopic]`.

## Гейты

- есть дословный вывод автора;
- есть 6 визуальных экземпляров для экскурсии или 3 для аргумента;
- нет универсального закона («любой», «все», «всегда», «каждый»);
- нет дубля уже выпущенной темы.

Гейт не пройден — `drop`. Ось ниже 2 или низкая взвешенная сумма — `bank`.
Веса и порог: `config/thresholds.yaml → topic_scoring`.

## Оси и будущие метрики

| ось | предсказывает |
|---|---|
| showable | удержание в середине |
| surprise | удержание на 3-й секунде |
| recognizable | раннее удержание и охват |
| social_currency | сохранения и пересылки |
| arguable | комментарии |
| supersystem | охват за пределами ядра |

До 15–20 опубликованных роликов веса — гипотеза. Калибровать надо попарные
корреляции «ось → метрика», а не общий total. Ось без сигнала удалить.
