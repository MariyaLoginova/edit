# EDIT-B1 · Метрики виральности тем

B1 ранжирует темы, но не выбирает их вместо человека. Контракт:
`TopicCandidate → list[ScoredTopic]`.

На первом проходе по книге темы и оценка привлекательности приходят **в одном**
LLM-вызове (`mine_and_score_book` / `mine_pastoureau_black.py`).

Отдельный B1 после A2 и любые батчи — только с явного согласия. См.
[`AGENTS.md`](../AGENTS.md).

## Гейты

Жёсткий `drop` только если:

- универсальный закон («любой», «все», «всегда», «каждый»);
- дубль уже выпущенной темы.

Не гейтят:

- отсутствие дословного вывода автора;
- мало визуальных экземпляров (это мягкая ось `showable`).

Ось ниже 2 (кроме `soft_axes`) или низкая взвешенная сумма — `bank`.
Веса и порог: `config/thresholds.yaml → topic_scoring`.

## Оси (приоритет аудитории)

| ось | предсказывает | роль |
|---|---|---|
| social_currency | пересылки / сохранения | главный |
| surprise | удержание на 3-й секунде, «необычный факт» | главный |
| recognizable | раннее удержание и охват | обычная |
| arguable | комментарии | обычная |
| supersystem | охват за пределами ядра | обычная |
| showable | визуальная полка | мягкая / вторичная |

До 15–20 опубликованных роликов веса — гипотеза. Калибровать надо попарные
корреляции «ось → метрика», а не общий total. Ось без сигнала удалить.
